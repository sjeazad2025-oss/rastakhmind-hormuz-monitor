# Rastakhmind Hormuz Maritime Monitor & Simulation Engine

A specialized repository dedicated to daily maritime security monitoring, logistics tracking, and systemic risk analysis in the Strait of Hormuz, using the **Rastakhmind Simulation Engine v2.0**.

## Evidence discipline

This repository separates three layers:

- **OBSERVED / EXTERNAL:** AIS/GNSS anomalies, vessel movements, reported maritime incidents, and other externally sourced observations.
- **MODEL OUTPUT:** `ΔC`, `α`, `β`, `s(t)`, `s_crit`, forecasts, and game-theoretic state calculations generated by the Rastakhmind simulation.
- **INFERENCE:** interpretations such as systemic escalation or crisis transition. Model forecasts are **not treated as proof of external reality**.

## Current monitoring scope

- **Logistics & congestion:** vessel queues and transit delays around Fujairah, Khor Fakkan, and Dubai, subject to source coverage and AIS limitations.
- **Navigation interference:** GNSS/GPS interference and AIS anomalies, with attribution to deliberate electronic warfare treated separately unless independently established.
- **Systemic risk calculation:** calibration of `ΔC`, `α`, `β`, and the critical threshold `s_crit = 0.18`.
- **Game theory:** strategic-state evaluation and phase-transition forecasting.
